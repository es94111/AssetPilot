# Google Play Store 圖像設計文件

本文件定義 AssetPilot Android App 上架 Google Play Store 時使用的圖像資產規格、設計方向與文案規範。

## 產品定位

AssetPilot 是個人資產管理 App，使用者透過 Android App 登入並管理收支、帳戶、預算、股票與報表資料。

重要定位：

- App 使用開發者架設與維運的 Server。
- App 不是要求使用者自行部署 Server 的「自架」產品。
- 對外文案應強調安全連線」、「資料加密」、「資產管理」，避免讓一般使用者誤解需要自行架站。

## Feature Graphic 規格

Google Play Feature Graphic 用於商店頁面頂部展示與行銷曝光。

必要條件：

- 檔案格式：PNG 或 JPEG
- 圖片尺寸：
- 檔案大小：不得超過 15 MB
- 建議檔案：`mobile/assets/google-play-feature-graphic.png`

設計注意事項：

- 重要內容需避開四周邊界，建議保留至少 48 px 安全距離。
- 不要放置過小的 UI 文字，手機商店頁縮圖時會難以辨識。
- 不要使用「自架」作為主文案。
- 不要暗示使用者必須自己安裝或維護 Server。
- 不要放入實際個資、真實財務資料、真實股票持倉或敏感畫面。

## 視覺方向

整體風格延續 AssetPilot 既有品牌語言：深色金融控制台、玻璃質感卡片、藍綠科技光暈與清楚的資產圖表。

核心感受：

- 專業：讓使用者相信 App 適合管理財務資料。
- 安全：以深色背景、藍綠光暈與加密文案傳達可信任感。
- 清楚：重點資訊要大、少、易讀。
- 現代：使用簡潔的儀表板圖形，不使用擬真雜訊或過度裝飾。

## 文案規範

推薦用語：

| 情境     | 建議文案                             |
| -------- | ------------------------------------ |
| 產品定位 | `連線至專屬伺服器的資產管理 App`   |
| 安全性   | `安全連線與資料加密`               |
| 功能總覽 | `記帳、預算、股票、報表，一站掌握` |

禁用或避免用語：

| 不建議文案                   | 原因                                              |
| ---------------------------- | ------------------------------------------------- |
| `自架`                     | 會讓 Google Play 使用者以為需要自行部署 Server    |
| `Self-hosted`              | 同上，與目前 App 上架定位不一致                   |
| `資料不上傳任何外部伺服器` | App 實際會連線到開發者架設的 Server，容易造成誤導 |
| `完全離線`                 | App 需要後端 API，不是離線 App                    |
| `銀行級安全`               | 若未提供相應合規證明，避免過度宣稱                |

## 截圖設計建議

Google Play 也會需要手機截圖。建議後續準備以下截圖：

| 截圖 | 畫面      | 重點文案                 |
| ---- | --------- | ------------------------ |
| 1    | 儀表板    | `總覽資產變化`         |
| 2    | 記帳      | `快速記錄收支`         |
| 3    | 預算      | `掌握每月預算`         |
| 4    | 股票      | `追蹤台股投資`         |
| 5    | 報表      | `用圖表看懂現金流`     |
| 6    | 設定/登入 | `安全登入與伺服器連線` |

截圖規範：

- 使用測試帳號與假資料。
- 金額、股票名稱、交易備註不得使用真實個資。
- 建議統一使用深色或淺色主題，不要混用過多風格。
- 每張截圖上方可加短標語，但不要遮住主要 UI。

## 交付檢查表

Feature Graphic 上傳前需確認：

- [ ] 圖片為 PNG 或 JPEG。
- [ ] 尺寸是否為 USER 指定大小
- [ ] 檔案大小小於 15 MB。
- [ ] 沒有使用「自架」或 `Self-hosted` 文案。
- [ ] 沒有真實個資或真實財務資料。
- [ ] 主要文字在縮圖狀態仍可辨識。
- [ ] 與 App icon、App 名稱、商店短描述風格一致。

## 後續維護

若 App 商店頁定位改為一般消費者使用，所有圖像與文案應維持「連線至專屬 Server」的描述。

若未來真的提供使用者自行部署版本，應另外製作不同版本的圖像與文案，避免 Google Play 頁面混用兩種產品定位。
