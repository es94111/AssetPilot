# Research: Frontend Next.js and Tailwind CSS Migration

## Decision: Next.js Architecture
- **Decision**: Hybrid approach (Next.js + Express API).
- **Rationale**: Minimizes migration risk while allowing modern frontend features.
- **Alternatives**: Complete rewrite (high risk, high effort).

## Decision: Tailwind CSS
- **Decision**: Tailwind CSS v4.
- **Rationale**: Faster build times, zero-config setup, modern CSS capabilities.
- **Alternatives**: Tailwind CSS v3 (legacy), plain CSS.
